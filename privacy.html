Privacy Policy

Effective date: September 5, 2026

This site is the public demonstration page for a reusable administrative interface. The demonstration itself is designed to run without a required account or third-party analytics service.

Information handled by the demo

The static demonstration does not ask visitors to submit personal information. A project that embeds this panel may connect it to its own authentication, database, APIs or other services. Those services are controlled by the host project, which is responsible for providing its own privacy notices and lawful data practices.

Local browser data

If a host project chooses to store preferences or application data in browser storage, that data remains subject to the host project's implementation. The reusable panel does not require a particular storage provider.

Security

The panel is a user-interface component. Authentication and authorization must be enforced by the host application's protected data layer. Sensitive credentials should not be placed in client-side code.

Changes

This policy may be updated when the demonstration or its data practices change. The effective date above identifies the current version.
